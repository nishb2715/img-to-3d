About the Tool

WHO
ARE
WE?

ImageCAD AI is a browser-based tool that converts ordinary photographs into interactive, editable 3D models. No 3D software experience required. No account. No setup.

Powered by Groq's LPU hardware and Llama 4 Scout's multimodal vision, the entire reconstruction pipeline runs in under five seconds — from raw image to orbitable 3D scene.

Every model is immediately editable via natural language or direct property controls, and exportable to formats compatible with Blender, Unity, and 3D printers.

Technology Stack

HOW IT
WORKS?

Three layers working in concert: vision AI, real-time 3D, and direct manipulation.

👁️
Multimodal Vision

Llama 4 Scout decomposes your image into named geometric primitives with position, scale, color, and material data encoded as structured JSON.

⚡
Groq Inference

Running on Groq's LPU chips, the model produces complete scene descriptions in milliseconds — enabling interactive, real-time iteration.

🌐
Three.js Renderer

Scene JSON parsed and rendered by Three.js with WebGL. Orbit controls, raycasting, shadow maps, and PBR materials run client-side.

🛠️
Python FastAPI Backend

A lightweight FastAPI server proxies Groq requests, handles image encoding, and streams responses back to the browser.

📤
Open Format Export

Three.js exporters generate standards-compliant GLB, OBJ, and STL files. JSON export preserves full scene state.

🕹️
Zero-Setup UX

No account. No install. No 3D expertise. The whole pipeline — upload, generate, edit, export — in one browser tab.
